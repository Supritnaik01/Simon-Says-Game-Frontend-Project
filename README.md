# 🎮 Simon Says Game

An interactive **Simon Says memory game** built using **HTML, CSS, and JavaScript**.  
The game challenges players to memorize and repeat an increasingly long sequence of colors, testing focus and short-term memory.

---

## 🧠 How the Game Works

1. Press **any key** to start the game.
2. The game flashes a random color tile.
3. Repeat the sequence by clicking the tiles in the same order.
4. Each level adds one new tile to the sequence.
5. A wrong move ends the game and resets progress.

---

## ✨ Features

- 🎯 Interactive memory-based gameplay  
- 🎨 Clean and modern UI with animations  
- ⚡ Visual feedback using flashes and transitions  
- ⌨️ Keyboard-based game start  
- 🔁 Automatic level progression  
- ❌ Game-over detection and reset logic  

---

## 🛠️ Tech Stack

- **HTML5** – structure  
- **CSS3** – layout, animations, transitions  
- **JavaScript (ES6)** – game logic, state management, DOM manipulation
